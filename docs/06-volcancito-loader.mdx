# 06 · Volcancito Loader

<p style={{fontSize: '1.05rem', color: 'var(--gg-ink-2)'}}><strong>Pregunta motora.</strong> ¿Cómo mantiene su dirección un robot cuando el terreno es irregular, como una calle en reparación o una ladera?</p>

El minicargador GuateGeeks introduce control de orientación usando yaw/giroscopio. Permite trabajar movimiento recto corregido, giros de 45 grados y pala frontal para pequeñas tareas urbanas o comunitarias.
