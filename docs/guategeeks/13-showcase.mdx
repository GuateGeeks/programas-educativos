# Showcase: robot autónomo SMARS

<p style={{fontSize: '1.05rem', color: 'var(--gg-ink-2)'}}>
Esta sección ayuda al docente a planificar el cierre del programa. Puede usarla para organizar
evidencias, orientar la demostración final y aplicar una evaluación coherente con el proceso vivido
por los equipos.
</p>

:::note Para el docente
Reserve 1 a 2 sesiones para el cierre. Cada equipo deberá presentar evidencia técnica: robot,
sketch usado, tabla de pruebas, calibración, explicación de una mejora y video o ejecución de la
misión autónoma.
:::
