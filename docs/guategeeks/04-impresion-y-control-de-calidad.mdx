# 04 · Piezas que Encajan

:::note Para el docente
Esta sesión enseña a rechazar. Es tentador aceptar toda pieza que «se ve bien» para no retrasar el
armado, pero una pieza mala descubierta en la sesión 5 cuesta mucho más que una rechazada aquí.
:::

<SessionModule id="s4">
  <SessionModule.Question>
    ¿Cómo se decide, sin adivinar, si una pieza sirve para el robot?
  </SessionModule.Question>

  <SessionModule.Context>
    En la sesión anterior el equipo midió y encontró error. Ahora tiene que usar esos números para
    decidir. Aceptar o rechazar no es cuestión de gusto: se define un criterio antes de mirar las
    piezas, y luego se aplica igual a todas. Esa inversión del orden —criterio primero, inspección
    después— es lo que distingue un control de calidad de una opinión.
  </SessionModule.Context>

  <SessionModule.Concepts items={[
    'Criterio de aceptación definido antes de inspeccionar',
    'Defectos típicos: warping, desplazamiento de capa, sobreextrusión',
    'Clasificación y trazabilidad',
    'Prueba de encaje como verificación funcional',
    'Ajuste de parámetros a partir de defectos observados',
  ]} />

  <SessionModule.Phase kind="act" label="Activar · 10 min" title="Dos piezas, una decisión">
    Mostrar dos piezas: una correcta y otra con un defecto visible. Preguntar cuál usarían y por
    qué. Presionar un poco: ¿y si la defectuosa fuera la única disponible? Ahí aparece la necesidad
    de un criterio explícito en lugar de una impresión personal.
  </SessionModule.Phase>

  <SessionModule.Phase kind="exp" label="Explorar · 15 min" title="Definir el criterio">
    El grupo acuerda su criterio de aceptación antes de tocar las piezas: tolerancia dimensional
    admisible, superficies sin deformación, ejes que giran libres, soportes removibles sin dañar.
    Se escribe en la pizarra y no se cambia durante la inspección.
  </SessionModule.Phase>

  <SessionModule.Phase kind="cre" label="Crear · 25 min" title="Inspeccionar el lote completo">
    Cada equipo inspecciona todas sus piezas aplicando el criterio acordado. Por cada una registra
    aceptada o rechazada, y en caso de rechazo, el defecto concreto. Las piezas rechazadas se
    fotografían: son la evidencia para ajustar la próxima impresión.
  </SessionModule.Phase>

  <SessionModule.Phase kind="ref" label="Reflexionar · 10 min" title="Del defecto al parámetro">
    Para cada tipo de defecto encontrado, proponer qué parámetro del slicer podría corregirlo.
    Cerrar conectando con lo que viene: las piezas aceptadas son las que se armarán en la sesión 5,
    y si el criterio fue laxo, se notará entonces.
  </SessionModule.Phase>

  <SessionModule.Materials items={[
    'Todas las piezas impresas del chasis y las orugas',
    'Calibrador o regla milimetrada',
    'Formato de control de calidad impreso',
    'Cámara para documentar piezas rechazadas',
    'Pinza de corte para retirar soportes',
  ]} />

  <SessionModule.Reto>
    Inspeccionen el lote completo y produzcan un reporte de control de calidad con el veredicto de
    cada pieza. Para cada rechazo, propongan el ajuste de parámetro que lo corregiría y expliquen
    por qué creen que funcionaría. Un rechazo sin propuesta de mejora es información incompleta.
  </SessionModule.Reto>
