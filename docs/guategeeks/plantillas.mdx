# Plantillas de registro

Formatos listos para imprimir o copiar. Están pensados para que la evidencia se produzca **durante**
el programa, no al final: la evaluación de la sesión 12 consiste en revisar lo que el equipo ya
generó.

<FlagNote tone="info" title="Cómo usarlas">
Imprima desde el navegador con Ctrl/Cmd + P, o cópielas a una hoja de cálculo compartida. No hacen
falta descargas: el contenido es el mismo aquí que en papel.
</FlagNote>

## Preparación de sesión · docente

Antes de cada clase.

```
Sesión n.º ____    Fecha ____    Docente ____

MATERIALES
[ ] Kits completos por equipo, según la sesión
[ ] Baterías cargadas y medidas (sobre 6.5 V)
[ ] Computadoras con Arduino IDE y permiso de puerto serie
[ ] Cables USB verificados
[ ] Material impreso de la sesión

ESPACIO
[ ] Mesas despejadas, suelo seco
[ ] Soporte para levantar el robot (sesiones 7 y 10)
[ ] Espacio de pruebas despejado (sesiones 10 a 12)

ROLES
[ ] Rotación anunciada y escrita a la vista

RIESGOS DE ESTA SESIÓN
_____________________________________________
```
