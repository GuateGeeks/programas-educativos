# Presentación final: diseñamos una ciudad con robots

<p style={{fontSize: '1.05rem', color: 'var(--gg-ink-2)'}}>
Esta sección ayuda al docente a planificar el cierre del programa. Puede usarla para organizar
evidencias, orientar la presentación final y aplicar una evaluación coherente con el proceso vivido
por los equipos.
</p>

:::note Para el docente
Reserve 1 a 2 sesiones para el cierre. Cada equipo deberá presentar 4 evidencias: foto del robot,
programa usado, tabla de pruebas y explicación de una mejora.
:::
