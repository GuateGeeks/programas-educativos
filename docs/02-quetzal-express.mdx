# 02 · Quetzal Express

<p style={{fontSize: '1.05rem', color: 'var(--gg-ink-2)'}}><strong>Pregunta motora.</strong> ¿Cómo diseñamos un robot que entregue un paquete de forma segura en una colonia, aldea o campus escolar?</p>

El robot simula un servicio de entrega local GuateGeeks: llevar medicina, refacción, libros o materiales a la persona correcta. Trabaja movimiento autónomo, subrutinas, apertura/cierre de compartimento, botones, pantalla del hub y lógica de acceso.

:::note Para el docente
Revise primero la pestaña **Implementación** (fases y conceptos), prepare los **Recursos** (programa base y guía), y cierre planificando con **CNB y estándares** y **Evaluación**. Puede rotar los roles del equipo —Constructor, Organizador, Programador— durante el módulo.
:::
