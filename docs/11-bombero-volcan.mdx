# 11 · Bombero Volcán

<p style={{fontSize: '1.05rem', color: 'var(--gg-ink-2)'}}><strong>Pregunta motora.</strong> ¿Cómo puede un robot ayudar en una emergencia sin exponer a una persona al peligro?</p>

Bombero Volcán entra a una casa, detecta distancia, eleva un brazo con sensor de color para localizar fuego y ejecuta una acción de neutralización o rescate. El módulo conecta tecnología con prevención y cuidado comunitario.

:::note Para el docente
Revise primero la pestaña **Implementación** (fases y conceptos), prepare los **Recursos** (programa base y guía), y cierre planificando con **CNB y estándares** y **Evaluación**. Puede rotar los roles del equipo —Constructor, Organizador, Programador— durante el módulo.
