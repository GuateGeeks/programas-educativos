# 09 · Elevador Tikal

<p style={{fontSize: '1.05rem', color: 'var(--gg-ink-2)'}}><strong>Pregunta motora.</strong> ¿Cómo sabe un elevador dónde está, a dónde debe ir y cuándo abrir sus puertas de forma segura?</p>

Este módulo introduce sistemas con estado mediante un elevador GuateGeeks para edificios, centros comerciales o bibliotecas escolares: variables de piso actual, piso seleccionado, máximo de pisos, puertas y sensor para referencia inicial.

:::note Para el docente
Revise primero la pestaña **Implementación** (fases y conceptos), prepare los **Recursos** (programa base y guía), y cierre planificando con **CNB y estándares** y **Evaluación**. Puede rotar los roles del equipo —Constructor, Organizador, Programador— durante el módulo.
:::
