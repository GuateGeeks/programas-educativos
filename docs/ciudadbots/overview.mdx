# CiudadBots Guatemala

Ruta docente para trabajar **robótica aplicada** con retos de ingeniería urbana. Aquí encontrará
la secuencia del programa, los recursos por módulo y la guía para llevar cada experiencia al aula:
implementación, seguimiento y evaluación en un solo lugar.
