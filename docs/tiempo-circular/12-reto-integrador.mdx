## Extensión opcional: una imagen en la carátula

Para equipos que terminen antes, o como profundización de **TAC 1.3**. Permite incluir un logo o
un dibujo propio en la carátula, cargado desde la memoria del programa. **No requiere tarjeta SD.**

### El procedimiento

1. Elegir una imagen en JPG o PNG, cuadrada y sencilla.
2. Convertirla a un arreglo de bitmap con un conversor de imagen a arreglo RGB565.
3. Redimensionarla a un **ancho máximo de 240 píxeles**. Si el PNG tiene zonas transparentes, hay
   que elegir con qué color se rellenan: la pantalla no sabe mostrar transparencia.
4. Crear una pestaña nueva en el Arduino IDE llamada `bitmap.h` y pegar ahí el arreglo.
5. Ajustar el ancho y el alto en el sketch para que coincidan con la imagen.

### La cuenta que hay que hacer antes

Una imagen que ocupe toda la pantalla pesa:

```
   240 × 240 píxeles × 2 bytes por píxel = 115 200 bytes ≈ 112 KB
```

Eso es mucho para un ESP32 que además tiene que levantar el stack de WiFi. **Antes de convertir una
imagen, calculen cuánto va a ocupar.** Una de 100 × 100 pesa 20 000 bytes, casi seis veces menos.
El límite deja de ser una regla arbitraria y pasa a ser una cuenta que el equipo puede hacer.

<FlagNote tone="warn" title="El detalle que hace perder una hora">
Si modifican `bitmap.h` y vuelven a compilar **sin tocar el `.ino`**, el Arduino IDE no se entera del
cambio y sigue usando la versión anterior. Basta con agregar y quitar un espacio en el `.ino` para
que lo note. Es un comportamiento del entorno, no un error del código.
</FlagNote>
