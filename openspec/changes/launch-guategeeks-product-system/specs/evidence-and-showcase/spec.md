## Purpose

Defines the evidence and showcase system that makes GuateGeeks programs visible and measurable for institutions.

## Requirements

### Requirement: Standard evidence set

Every pilot or program SHALL define a standard evidence set including attendance/session log, student artifact, photos or clips, rubric, teacher feedback, student reflection, and leadership summary.

#### Scenario: Pilot ends
- **WHEN** a pilot ends
- **THEN** GuateGeeks can produce an evidence package without reconstructing the process from memory.

### Requirement: Impact report

GuateGeeks SHALL define a concise impact report format for directors, sponsors, or partner institutions.

#### Scenario: Director asks what happened
- **WHEN** leadership reviews the pilot
- **THEN** GuateGeeks can present outcomes, evidence, observations, and recommended next steps.

### Requirement: Showcase format

Each program format SHALL define whether it includes a mini showcase, full showcase, parent presentation, or sponsor presentation.

#### Scenario: Program reaches final session
- **WHEN** students complete the program
- **THEN** there is a defined format for presenting student work and learning evidence.

### Requirement: Evidence permissions

Before collecting public-facing photos, videos, testimonials, or case-study content, GuateGeeks SHALL confirm permissions with the client.

#### Scenario: Case study is drafted
- **WHEN** GuateGeeks wants to use pilot evidence externally
- **THEN** the team checks permission status before publishing or sharing.
