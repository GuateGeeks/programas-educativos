## MODIFIED Requirements

### Requirement: Hub branding and landing

The site SHALL present GuateGeeks branding (logo, theme) and a landing page that introduces the hub and links to **every** available program. When a program is added, the landing page, navbar and footer SHALL each gain an entry for it, and the landing page SHALL indicate which grades of the Ciclo Básico each program targets so a teacher can choose between them.

#### Scenario: Landing page links to CiudadBots

- **WHEN** a visitor loads the hub landing page
- **THEN** the page displays GuateGeeks branding and provides a navigable link into the CiudadBots program

#### Scenario: Landing page links to every program

- **WHEN** a visitor loads the hub landing page
- **THEN** it provides a navigable link into each published program — CiudadBots, GuateGeeks SMARS and Tiempo Circular — and states the grade each one targets

#### Scenario: Navbar and footer list every program

- **WHEN** any page of the site is rendered
- **THEN** the navbar offers a sidebar entry per program and the footer's "Programas" section lists each program

## ADDED Requirements

### Requirement: Tiempo Circular occupies its own route namespace

The Tiempo Circular program SHALL live under the `/tiempo-circular/*` route namespace, supplied by a `docs/tiempo-circular/` directory and its own autogenerated sidebar, without altering any existing route.

#### Scenario: Program content is namespaced

- **WHEN** a visitor navigates to a Tiempo Circular session
- **THEN** its URL is under the `/tiempo-circular/` path prefix

#### Scenario: Adding the program does not move existing routes

- **WHEN** the site is built with the new program present
- **THEN** all existing `/ciudadbots/*` and `/guategeeks/*` routes resolve unchanged, and the build reports zero broken internal links

### Requirement: English locale declares the language limitation for Tiempo Circular

Because Tiempo Circular is authored only in Spanish, the English locale SHALL serve an explicit stub for that namespace rather than silently falling back to untranslated Spanish content.

#### Scenario: English visitor is told the content is Spanish-only

- **WHEN** a visitor selects the English locale and navigates into the Tiempo Circular namespace
- **THEN** an English-language page states that this program's content is currently available in Spanish only and links to the Spanish version

### Requirement: Static assets for Tiempo Circular are hosted under their own namespace

Media for the program SHALL be served from `static/assets/tiempo-circular/`. Third-party imagery reproduced there SHALL be traceable to its source.

#### Scenario: Program images resolve

- **WHEN** a Tiempo Circular page requests a wiring or screen photograph
- **THEN** the image is served from `static/assets/tiempo-circular/` at a stable URL

#### Scenario: Reproduced tutorial images keep their provenance

- **WHEN** an image copied from `watch/esp32-round-circular-tft-lcd-display-assets/` is served from `static/assets/tiempo-circular/`
- **THEN** its filename is preserved or mapped in a manifest, and the program's licences page names esp32io.com / DIYables as the source of every such file
