## ADDED Requirements

### Requirement: Overview page introduces current international standards sources
The overview page SHALL present the program-level international standards framing using current source names: ISTE Standards for Students, 2026 CSTA PK-12 Computer Science Standards, and NGSS MS-ETS1 Engineering Design.

#### Scenario: Teacher reviews program-level standards sources
- **WHEN** a teacher opens the CiudadBots overview page
- **THEN** the international standards explanation SHALL use current ISTE, CSTA 2026, and NGSS MS-ETS1 naming

## MODIFIED Requirements

### Requirement: Overview page presents the transversal CNB block
The overview page SHALL present the transversal CNB alignment block covering `Matemática`, `Ciencias Naturales`, `Tecnologías del Aprendizaje y la Comunicación`, `Comunicación y Lenguaje, Idioma Español`, and `Emprendimiento para la Productividad` at the program level. The block SHALL describe how robotics evidence supports each area without requiring teachers to infer the connection from broad labels alone.

#### Scenario: Teacher needs a program-level CNB summary for reporting
- **WHEN** a teacher opens the overview page
- **THEN** the five transversal CNB areas SHALL be present with descriptive text tied to CiudadBots student evidence
