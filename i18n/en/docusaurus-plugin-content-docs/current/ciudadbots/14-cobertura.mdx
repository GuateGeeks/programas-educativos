# Teacher coverage and tracking

This page is the teacher's progress dashboard. Select a grade and group before marking classes
as implemented. Detailed session content remains inside each module; this view focuses only on
progress visibility.

## How to use it

1. Select **Grade 7, Grade 8, or Grade 9** to load the corresponding route.
2. Create or select the **active group**. Each grade can have its own groups.
3. Choose the guided route or open challenges, then mark each class or block as you teach it.
4. Return whenever needed: progress is saved in this browser, separately for each grade and group.

This is a teacher planning tool. It does not store student names or represent individual grades.
