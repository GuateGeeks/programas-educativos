# Final presentation: we designed a city with robots

<p style={{fontSize: '1.05rem', color: 'var(--gg-ink-2)'}}>
This section helps the teacher plan the program's closing. Use it to organize evidence, guide the
final presentation, and apply an evaluation consistent with the process each team went through.
</p>

:::note For the teacher
Reserve 1 to 2 sessions for the closing. Each team should present CNB and international evidence:
a photo or video of the robot, the program used, a test table, an explanation of one improvement,
and a connection to a local need or safety criterion.
:::
