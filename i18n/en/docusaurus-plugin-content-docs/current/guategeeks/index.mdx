# GuateGeeks · SMARS Aula Autónomo

<FlagNote tone="warn" title="This program is published in Spanish only">

## What the program is

A **12-session** program in which teams build a tracked robot that detects obstacles, decides a
manoeuvre and moves on its own. No phone, no Bluetooth, no companion app: the robot is operated with
two buttons and answers with a buzzer.

It targets **tercero básico**, the final year of Guatemala's lower-secondary cycle, roughly
equivalent to grade 9. Its curricular alignment cites the third-year competencies specifically, and
international standards at the matching band: CSTA Level 3A, NGSS HS-ETS1 and ISTE sub-indicators.

It is programmed for Arduino Uno with an **L293D Motor Shield v1-compatible driver**. The motor
sketches use `AFMotor`; the non-motor sketches use the Arduino core only. It complements
[CiudadBots](/ciudadbots), which teaches applied robotics with visual blocks, covers all three
years of the cycle, and **is** available in English.

## Structure

- Four phases — Activar, Explorar, Crear, Reflexionar — repeated as a mini-cycle inside every session
- Four rotating team roles: safety, mechanics, electronics, code
- Five layered Arduino sketches, each testing one subsystem before integration
- Challenge levels rising from documenting to full engineering integration

## Hardware

Arduino Uno, L293D Motor Shield v1-compatible driver, two N20 gearmotors with tracks, an HC-SR04
ultrasonic sensor, two buttons and a passive buzzer.
