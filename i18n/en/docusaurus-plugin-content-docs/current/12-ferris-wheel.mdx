# 12 · Ferris Wheel

:::note For the teacher
Review the **Implementation** tab first (phases and concepts), prepare the **Resources** (base
program and guide), then close out planning with **CNB & Standards** and **Evaluation**. You can
rotate team roles — Builder, Organizer, Programmer — throughout the module.
:::

<Module id="m12">
  <Module.Question>
    How do we design a fun fair ride that's also safe?
  </Module.Question>

  <Module.Context>
    The technical closer turns the carousel into a fair ride. It works with speed control, tilt,
    smooth acceleration, variables, parallel programs, and an emergency stop.
  </Module.Context>

  <Module.Concepts items={[
    "Smooth acceleration",
    "Speed variable",
    "Parallel control",
    "Motorized tilt",
    "Emergency stop",
  ]} />

  <Module.Phase kind="act" label="Activate · 12 min" title="Fun and safety">
    Ask what makes a mechanical ride safe. Why shouldn't it start or stop abruptly?
  </Module.Phase>

  <Module.Phase kind="exp" label="Explore · 25 min" title="Motors and controls">
    Identify the rotation motor, tilt motor, hub buttons, and force sensor. Define safe limits.
  </Module.Phase>

  <Module.Phase kind="cre" label="Create · 70-100 min" title="Manual and autonomous mode">
    Build the Ferris Wheel. Program a gradual speed increase, tilt control, and an emergency stop.
  </Module.Phase>

  <Module.Phase kind="ref" label="Reflect · 20 min" title="Engineering showcase">
    Present the machine, explaining which program runs in parallel, which variable it controls, and
    how the user is protected.
  </Module.Phase>

  <Module.Cnb items={[
